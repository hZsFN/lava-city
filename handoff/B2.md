**行为口径（B1 集成时注意）**

1. **冷却初值为 0 = 就绪**：塔建好（`onPlaced`）后第一帧满足射程即开火，不是等一个 `intervalSec`。
2. **射程判定用 `self.cfg.range`**，不是 `self.range` —— `TowerRuntime` 上没有 `range` 字段（`range` 只在 `TowerBehavior` 上）。B1 构造 runtime 时请保证 `cfg` 是 `towers.json` 里 `kinds[kind]` 那一份。
3. **`canFire === false` 时**：弩炮/符文/震地锚完全不开火；寒晶额外按 `freeze.decayPerSec` 衰减冻结值。
4. **寒晶衰减只在「打不到目标」时发生**（不在射程 / 不能开火），冷却期间不衰减。否则 `+8/1s` 对 `-6/s` 永远涨不上去。
5. **震地锚**：装填期无论掷中与否都重置为 `intervalSec`（掷不中也进装填，避免逐帧狂掷）；一次施法窗口内每装填周期最多一次请求。
6. **嘲讽图腾**：`taunted=true` 时不抢别人的嘲讽；`onRemoved` 时若自身嘲讽仍在计时则发 `TauntEnded`（已发过则不重复）。计时用 `1e-9` 容差，避免固定步长浮点残差导致嘲讽永不结束。
7. **塔只发事件，不改 Boss 状态**；`DebuffStackChanged` / `BossSkillInterrupted` 一律不发（单测里有负向断言守着）。

## 环境注意（给 S0 / B1 / B3）

`npm run gate` 在本会话**沙箱内会 `spawn EPERM`**：`vitest` 启动 esbuild 子进程（管道 stdio）被沙箱拒绝，表现为 `failed to load config from vitest.config.ts → Error: spawn EPERM`，`[gate] FAIL test`。这不是代码问题。提权（danger-full-access）后同一条命令全绿：

```
===== [contract] =====  OK
===== [typecheck] ===== OK
===== [test] =====      Tests 98 passed (98)
===== [build] =====     OK
===== [pack] =====      全部通过（共 8 项）
[gate] ===== 全部通过 =====
```

另外：**不要用 PowerShell `Set-Content` 批量改这些 .ts 文件**——会把 UTF-8 中文注释写成 GBK 乱码（我踩过一次，已整文件重写修复）。批量替换请用编辑器工具或 `write` 重写整个文件。
