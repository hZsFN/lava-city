**行为口径（B1 集成时注意）**

1. **冷却初值为 0 = 就绪**：塔建好（`onPlaced`）后第一帧满足射程即开火，不是等一个 `intervalSec`。
2. **射程判定用 `self.cfg.range`**，不是 `self.range` —— `TowerRuntime` 上没有 `range` 字段（`range` 只在 `TowerBehavior` 上）。B1 构造 runtime 时请保证 `cfg` 是 `towers.json` 里 `kinds[kind]` 那一份。
3. **`canFire === false` 时**：弩炮/符文/震地锚完全不开火；寒晶额外按 `freeze.decayPerSec` 衰减冻结值。
4. **寒晶衰减只在「打不到目标」时发生**（不在射程 / 不能开火），冷却期间不衰减。否则 `+8/1s` 对 `-6/s` 永远涨不上去。
5. **震地锚**：装填期无论掷中与否都重置为 `intervalSec`（掷不中也进装填，避免逐帧狂掷）；一次施法窗口内每装填周期最多一次请求。
6. **嘲讽图腾**：`taunted=true` 时不抢别人的嘲讽；`onRemoved` 时若自身嘲讽仍在计时则发 `TauntEnded`（已发过则不重复）。计时用 `1e-9` 容差，避免固定步长浮点残差导致嘲讽永不结束。
7. **塔只发事件，不改 Boss 状态**；`DebuffStackChanged` / `BossSkillInterrupted` 一律不发（单测里有负向断言守着）。

## 环境注意（给 S0 / B1 / B3）

**1. 沙箱 `spawn EPERM`**（已由 S0 在 `acfdce0` 用 `gate:fast` 解决）

`vitest` / `vite build` 会启动 esbuild 子进程（`stdio: 'pipe'`），DSH 受限沙箱禁止子进程创建命名管道 → `spawn EPERM`。日常自检用 `npm run gate:fast`（contract + typecheck，不弹窗）；提交前跑全量 `npm run gate`。

**2. `vite build` 的第二个坑：`%TEMP%` 权限**

即使提权，`vite build` 仍可能报 `remove C:\Users\...\Temp\esbuild-xxx: Access is denied`。`scripts/gate.ps1` 已经把 `$env:TEMP` 指到仓库内 `.tmp/` 来规避；**但直接手跑 `npx vite build` 不会**，要先设：

```powershell
$env:TEMP = "E:\demo\p2b-2\.tmp"; $env:TMP = $env:TEMP
```

**3. 不要用 PowerShell `Set-Content` 批量改 .ts 文件**

会把 UTF-8 中文注释写成 GBK 乱码（我踩过一次：五个塔文件的中文注释全变 `鍢茶鍥捐吘`，只能整文件重写修复）。批量替换请用 `edit` 工具，或 `write` 重写整个文件。
