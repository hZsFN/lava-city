## 已完成

### 1. 契约 v1.1.1（`src/core/events.ts`）— 已冻结
相对 M0 票附录**纯增量**，已存在的事件名与字段一个未改：

**新增 4 个事件**
| 事件 | 用途 |
|---|---|
| `TowerHpChanged { towerId, hp, maxHp }` | 塔耐久（`TowerPlaced` 不带 hp，place 后必须立刻发一次） |
| `FreezeProgressChanged { value, max }` | 寒晶冻结值进度（UI 进度环 + Boss 判定共用） |
| `TowerSlotStateChanged { slotId, state }` | 塔位 `locked/open/occupied/submerged` 状态机 |
| `TowerInterruptRequested { towerId, skill, chance }` | 震地锚请求打断，Boss 掷骰后才发 `BossSkillInterrupted` |

**`Snapshot` 新增 5 个字段**：`phaseEndsAtSec`、`towerSlots`、`lavaY`、`score`（+ 类型 `SlotState`）

**`Bus` 新增 1 个内部 API**：`__setSnapshot(next: Snapshot)`
> 只有逻辑层 owner 与单测可调用；渲染层/UI **严禁**。

**归属规则（文末注释）**
1. `DebuffStackChanged` 由 **Boss** 统一发；塔只发 `TowerTargetHit`
2. `BossSkillInterrupted` 由 **Boss** 发；塔发 `TowerInterruptRequested`
3. `MatchEnded` 由 **flow** 发一次且仅一次
4. 渲染/UI 只允许 `on()` + `snapshot()`，禁止 `emit()`
5. 逻辑层禁止 `import three`

## 对外暴露的接口（别人可以依赖的）

```ts
// src/core/events.ts
export type Vec3 = readonly [number, number, number];
export type Attr = 'arcane' | 'physical';
export type BodyPart = 'core' | 'back' | 'kneeL' | 'kneeR';
export type MatchPhase = 'wake' | 'prep' | 'boss1' | 'transition' | 'boss2' | 'rage' | 'ended';
export type SlotState = 'locked' | 'open' | 'occupied' | 'submerged';
export interface Bus {
  on<K extends EventName>(k: K, fn: (p: Events[K]) => void): () => void;
  emit<K extends EventName>(k: K, p: Events[K]): void;
  snapshot: () => Snapshot;
  __setSnapshot(next: Snapshot): void;   // 内部 API，渲染/UI 禁用
}
export function createBus(): Bus;

// src/core/rng.ts
export type Rng = () => number;
export function createRng(seed: number): Rng;
export function hashSeed(text: string): number;
```
