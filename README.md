## 三、这一关有你扮演谁
- **位置**：塔顶平台，中心是「熔心核」塔心——它被摧毁代表失败。
- **血量是接力棒**：从上一位玩家的存档接力进来，上一关剩多少就带多少（可能只剩 1 点）。**本关不回血**，被打就少。
- **掉血**：被 Boss 技能命中按各技能判定范围**固定扣 1 点**（有短受击无敌，避免连扣）。
- **阵亡**：血量归 0 → 黑屏「塔心熄灭了」→ 判定本关失败 → 交给下一关。
- **移动**：WASD / 空格跳 / Shift 冲刺（冲刺有短无敌帧）。
- **俯视建塔**：按 **B**（或右上角「俯视建塔」按钮）切到战术俯视，用鼠标点塔位建塔 / 换塔。

## 四、游戏怎么玩（机制拆解）
### 4.1 你的身手：双形态武器（按 Q 切换）
| 形态 | 左键 | 右键 |
|---|---|---|
| **物理形态**（长剑 / 长刀）| 轻攻击连击 | 重攻击（蓄力劈砍）|
| **奥术形态**（奥术手枪）| 连发奥术弹 | 特殊攻击（有过热条 / 冷却）|
武器模型和贴图在 `public/models/`（含这把手枪和刀的 GLB 模型与纹理）。
### 4.2 你的防御塔（5 种）
塔的核心作用不是"输出"，而是**控制 + 制造破绽**。屏幕右下角有常驻建塔面板，实时显示每种塔的伤害 / 射程 / 造价 / 特效。
| 塔 | 属性 | 作用 |
|---|---|---|
| **弩炮塔** | 物理 | 叠「碎甲」，降低 Boss 物理抗性 |
| **符文塔** | 奥术 | 叠「灼烙」，降低 Boss 奥术抗性 |
| **霜冻塔** | 奥术控制 | 累积冻结值，满值让 Boss 定身 2.5 s |
| **震地塔** | 物理控制 | Boss 施法时掷地打断施法 |
| **图腾塔** | 无 | 嘲讽 Boss 转身露背，解锁背部弱点 |
- **塔位共 11 个**：中环 + 塔身 + 外环。开场只有一部分解锁，阶段推进后熔岩上涨、外环解锁。
- 塔满了可以**换塔**（旧塔按折价回收熔核）或**拆塔**。
### 4.3 伤害与「破绽」——核心爽点
- Boss 有两个形态，**抗性互换**：
  - **阶段 I 岩甲形态**：奥术抗 70%、物理无效——弱点是**地脉核心（物理）**。
  - **阶段 II 熔火形态**：物理抗 70%、奥术无效——弱点是**背部裂缝 + 双膝（奥术）**。
- 用塔控制让 Boss **弱点暴露**时，用**匹配属性**持续攻击累积「破绽值」到满 → 弱点变成"可击破" 3 秒。
- 按 **F 处决**：1.2 秒慢镜演出，造成当前阶段最大血量 **12% 真实伤害** + 眩晕。
- 伤害公式：`基础 × (1 − 抗性 + 减抗debuff) × 弱点倍率`（弱点且属性匹配才能打出爆发）。
### 4.4 伊格纳斯的招数（8 个技能）
| 技能 | 表现 |
|---|---|
| **岩拳横扫** | 正面大扇区横扫 |
| **跃击** | 高高跃起砸向玩家落点 |
| **吸蚀塔心** | 贴近塔心，正吸它的能量回血 |
| **岩柱** | 在周围升起石柱 |
| **吐息** | 正面锥形熔岩喷吐 |
| **冲撞** | 高速朝玩家俯冲 |
| **流火** | 头顶落下火雨（会打塔）|
| **自燃** | 原地爆发范围伤害，并清掉身上的减抗 debuff |
配了一个 **Boss 导演（director）**：长时间打不出弱点时会适当放水，让玩家"贪刀"时又会加强施压——保证每一局都有节奏。
### 4.5 一局时间轴
| 时段 | 阶段 | 发生了什么 |
|---|---|---|
| 0–16 s | 苏醒 | 黑屏 → 睁眼 → 俯瞰熔岩海（旁白引导）|
| 16–40 s | 教程 | 一本浮空「教程书」，按 **E** 翻阅，学建塔与补刀 |
| 40–50 s | 准备期 | Boss 即将登场 |
| 50–140 s | **阶段 I 岩甲** | 奥术弱点（地脉核心）|
| 140–155 s | 转阶段 | Boss 沉入熔岩、形态切换、熔岩上涨、外环塔位解锁 |
| 155–245 s | **阶段 II 熔火** | 物理弱点（背部 + 双膝）|
| 245–270 s | 狂暴 | 熔岩加速上涨，270 秒整淹没塔心 = 失败 |
**结束判定：** Boss 死 = 胜利（有碎甲 + 光束 + escape 演出）；塔心被毁 / 玩家阵亡 / 熔岩吞没 / 超时 = 失败。

**✅ 已进驻主场景**
- **完整 Boss 战**：`IgnisBoss` 实体（美术换成了「苏尔特」模型 `SurtrAdapter`）从熔岩口登场，8 个技能 + AI 大脑 + 弱点机制全部在主场景跑通。
- **玩家战斗**：鼠标 → 武器 → 相机射线 → Boss 命中判定（含巨型目标的包围盒兜底采样），击杀有 victory 演出。
- **弱点 / 破绽 / 处决**：`WeaknessMeter` 破绽累积 + `Execution` F 处决慢镜 — 都已落地。
- **玩家控制器**：手写 AABB 物理（移动 / 冲刺 / 跳跃 / 受击），掉进熔岩不会无限坠落（会送回最后一次站稳点）。
- **游戏主循环**：渲染帧 → 固定 60Hz 逻辑推进 → 表现同步。
- **塔系统**：11 塔位、5 种塔、俯视点选建塔 / 换塔 / 折价回收、右下角实时数值面板。
- **剧情层**：表里双世界 + 五幕（迷惘·成长·舍弃·决绝·新生），逻辑与表现分离、可在 Node 下单测。
- **HUD（M5）**：Boss 血条、弱点方向指示、熔核、状态提示。
- **渲染**：WebGPU 渲染器（无 GPU 自动回退 WebGL2）、程序化熔岩、塔位、角色 + 武器模型、暗岩石纹理。
