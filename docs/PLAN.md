## 三条贯穿全程的硬规定

### 一、`src/core/events.ts` 只有总指挥能改

任何人要加事件或字段，走"契约申请"（在 PR 描述里写清名称、字段、触发时机），由总指挥合并后广播。

**今天最致命的失败模式**：三个 Agent 各造一套事件，15 点联调时发现彼此对不上。

### 二、每人只写自己的目录

| 目录 | 归属 |
|---|---|
| `src/render/` | 渲染 Agent |
| `src/boss/` | Boss Agent |
| `src/player/` `src/combat/` `src/towers/` `src/flow/` `src/ui/` `src/audio/` | P2 |
| `src/core/` | 总指挥（契约与配置结构） |
| `tools/` `docs/` `kit/` | 例外：`docs/tickets/` 只由总指挥写 |

跨目录要发请求，不要直接改。

### 三、17:00 之后不新增功能

谁提新功能，堵回去。只听 bug。

## 目录与文件约定

- 交付入口：`index.html` 在包根，先加载 `shared/save-protocol.js` 再加载 `./src/main.ts`
- 构建：`vite build` → `out/`，`base: './'`
- 打包：`npm run pack` → `release/lava-city.zip`，内部对 ZIP 跑 `check.mjs`
- 自检：`node kit/tools/check.mjs out/`
- 生成物不进 git：`out/` `release/` `dist/` `.vite/` `node_modules/`

## 已知风险清单

| 风险 | 触发条件 | 应对 |
|---|---|---|
| WebGPU 在隔离 iframe 拿不到 adapter | 大厅自测时 | 切 `new WebGPURenderer({ forceWebGL: true })`，只改 renderer 初始化 |
| 三个 Agent 各造事件 | 联调时类型对不上 | 契约独占 + 每半小时查 conflict |
| 打包体积超 12 MB | 引了 GLB 或大贴图 | 程序化生成，不引外部模型 |
| 17:00 前跑不完一局 | 玩法进度落后 | 用 G4 降级预案，压到 2 分钟 |
