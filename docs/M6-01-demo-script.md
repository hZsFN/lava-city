# M6-01 · 路演脚本（5 分钟：3 分钟演示 + 2 分钟衔接说明）

> 依据赛事规则：18:00–19:00 连锁通关路演，每队 5 分钟 = **3 分钟通关演示 + 2 分钟衔接说明**。
> 本文件是现场照读的东西，不是设计文档。

## 【开场前 30 秒：把风险掐死】

开场前必须做完这五件事，缺一件就别开始：

1. **用赛事大厅的环境跑，不是本地 5173。** 大厅是 sandboxed iframe，`WL` 对象从 `worldline.js` 来；本地跑没有 WL，`completeLevel` 会静默失败——看着通关了，实际没交卷。
2. **提前通过一次。** 用同一台机器跑完整一局，确认能从 `wake` 走到 `escape` 并真的触发 `WL.completeLevel`。
3. **关掉所有其他标签页和 DevTools。** 核显 + 后处理，多开一个标签就掉 10 帧。
4. **音量调到能听清但不刺耳**，确认 BGM 起来了（这游戏大部分队会忘开声音，我们有声音就是优势）。
5. **鼠标先点一下页面**——AudioContext 要用户手势才能创建，不点就是静音。

## 【3 分钟演示：分镜与话术】

演示者站在画面右侧，不要挡住中央。手放在 WASD 上，鼠标随时准备转头。

| 时间 | 画面要发生什么 | 你嘴上说什么 |
|---|---|---|
| **0:00–0:15** | 黑屏 → 睁眼，浮字浮现 | "这里本来是一座塔的塔心。你醒来的时候，熔岩已经涨到脚下了。" |
| **0:15–0:35** | 走到书前按 E，翻三页 | "地上有一本前任留下的册子。三页——它教你建塔、切形态、以及怎么在它身上开一个洞。" |
| **0:35–0:50** | 建第一座塔，塔从地面长出来 | （不说，让音效说话）"建塔"三音上行的声音是这一段的主角 |
| **0:50** | **Boss 从熔岩里升起** | "它来了。伊格纳斯——上一次守塔的人给它起的名字。" |
| **0:50–1:40** | 阶段 I 战斗：打弱点、破绽环攒满、按 F 击破 | "它的岩甲只认物理，法术打上去只有三成。但它有四个地方是软的——胸口、后背、两个膝窝。打对地方，环会满，满了按 F。" |
| **1:40–1:55** | **转阶段过场** | （等 Boss 说完第一句再开口）"它说'你居然还站着'。然后它站起来了——注意，它变高了，而且抗性反过来了，现在它怕法术。" |
| **1:55–2:40** | 阶段 II 战斗：切到法术形态、塔被打、熔岩上涨 | "熔岩在涨。塔会掉，掉了要重建。这就是这个关卡真正的时间压力——不是倒计时，是脚下在往上淹。" |
| **2:40–2:50** | **击破**：Boss 碎成 40 块、光柱冲天 | （闭嘴，让画面说话。这一段是全片最高潮） |
| **2:50–3:00** | 传送：第三人称绕塔、白光、结束 | "塔守住了。而这座城市顶端，还有更暗的东西在等——那是下一棒的世界。" |

**三条铁律：**

1. **不要说技术。** 不提 WebGPU、不提 draw call、不提"我们自己写的 shader"。评审要在 3 分钟里感受这个东西，不是听架构。
2. **每一句话都要指向画面上的东西。** 说"四个地方是软的"的时候，准星必须正对着弱点。
3. **如果卡住超过 20 秒，立刻跳过。** 演示不是通关验证，宁可说"这里我直接跳到第二阶段"。

## 【2 分钟衔接说明：三张纸】

这一段是**给下一个世界的人交代**，不是给自己吹。

### 第一张：入口承接（30 秒）

> "我们接的是上一棒的存档。这一关不预设血量——可能满血进来，也可能只剩 1 点。所以我们做了三件事：不设计任何回血机制、被打了就少、没被打就不变；血条永远显示 `hp/max_hp` 而不是百分比；血归零就判失败，不偷偷复活。"

**要点**：让评审知道我们**读了规则**，不是自己发明了一套。

### 第二张：出口钩子（60 秒）

> "我们传出去三样东西。
> 第一件通用道具：**熔心余烬**——进入下一关时攻击 +1。它是个烧红的核，别的世界也能用。
> 两条线索：第一条是 Boss 死前说的那句'……你居然还站着'——它见过很多次，说明这个循环不是第一次；第二条是塔心护罩裂开后露出的石阶，它通往城市更上面。
> 我们的结束语是：**『塔心的护罩裂开了。你脚下不是地面，是一段往下沉的石阶——而城市顶端，还有更暗的东西在等着。』**"

**要点**：道具合法（`attack +1` 在白名单里）、线索 ≤ 2、结束语给下一棒留了明确的接续方向。

### 第三张：世界观融合（30 秒）

> "我们的世界是『熔岩地心城』第 21 号——官方给的故事是『岩浆每分钟上涨一米，出口在城市最顶端』。所以我们没做一个普通的 Boss 战，我们做的是**在一座正在下沉的塔上，边打边往上爬**。熔岩上涨不是背景动画，它是真的每秒钟在抬高，碰到你就会掉血。"

**要点**：直接引用官方的世界设定原文，证明"可玩性与世界观融合"这 30 分不是硬凑的。

## 【故障预案】

| 现场出什么 | 怎么办 |
|---|---|
| 页面打不开 / 白屏 | 立刻说"我们准备了录屏"，切备用视频。**别在现场调试。** |
| 帧率掉到 20 以下 | 按 `[` 或调试面板切到 low 档（关 GTAO/SSR/体积光），嘴上说"为了现场流畅我们降了一档画质" |
| 声音没起来 | 点一下画面，或者说"（声音需要交互激活）"然后继续 |
| 中途死掉 | **这是好机会**，别慌："看到了吗，血归零不是读档，是这一局结束了——这是规则要求的。"然后按 R 重开 |
| Boss 不打人 / 卡住 | 直接说"我们用调试键跳到第二阶段"，按 `2` |
| 超时（熔岩淹到塔顶） | 这是最坏情况。如果还有 1 分钟以上，按 R 重开；如果只剩 30 秒，直接跳到胜利（调试键） |
