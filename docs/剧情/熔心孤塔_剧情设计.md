## 一、一句话

> **你不是第一个来这座塔的人。塔心不是机器，是上一个不肯走的人留下的心跳；而你要打的那个"魔王"，是唯一还在替它守夜的人。**

## 二、为什么要有表里世界（机制即叙事）

本作单局只有 **4:30**，没有时间播过场动画。所以剧情不能"停下来讲"，只能**在战斗的缝隙里渗出来**。

于是采用**双世界**：

| | 表世界（surface） | 里世界（inner） |
|---|---|---|
| 画面 | 橙红熔岩、黑曜石孤塔、火星上浮 | 冷青、降饱和、边缘结晶化、时间几乎静止 |
| 玩家在做什么 | 建塔、闪避、击破 | **什么都做不了，只能听**（0.4–1.2 秒，不打断操作） |
| 叙事功能 | 讲"发生了什么" | 讲"为什么会这样" |
| 触发时机 | 阶段推进、布塔、受伤 | **Boss 转阶段、弱点暴露、击破、膝盖碎裂、冻结满、死亡** |

**核心设计：里世界只在"战斗最激烈的那一瞬"打开。**

- Boss 的岩甲张开、露出蓝色核心的那 3 秒 → 玩家眼前一冷，听见一句不属于这个世界的记忆；
- Boss 从岩甲形态蜕成熔火形态的 15 秒转阶段 → 玩家整段坠入里世界，看见这座城是怎么沉的；
- 击破（处决）的 1.2 秒慢镜 → 里世界与表世界同时存在，慢镜里多一句旁白；
- 玩家死亡 → 里世界变成"走马灯"，但只给一句。

这不是"战斗时弹出对话框"，而是**战斗本身就是叙事的节拍器**。你打得越狠，看到的越多；你越强，越接近那个不想知道的真相。

技术上：里世界用 **canvas 的 CSS filter + 叠加层**实现（`saturate(.3) contrast(1.28) hue-rotate(148deg)` + 冷青暗角 + 结晶化），不碰渲染管线、不消耗 GPU、WebGPU 与 WebGL 回退两条路都生效。每次进入里世界，屏幕边缘的"结晶"累加一层——**这是玩家的进度条，也是他的异化程度**。

## 三、世界与人物

### 3.1 熔岩地心城（第 21 号世界）

一座正在沉下去的城市。岩浆每分钟上涨一米，出口在最顶端。

**但这不是自然灾害。** 这座城建在一颗**还在跳的心**上面——「熔心」。城靠这颗心的热量活着，也因为它而必须一直往下沉：心每跳一次，地火就涨一寸。城里的人一代代往上搬，搬到无处可搬，最后只剩塔顶。

### 3.2 三个存在

**① 你（玩家）**

从上一关逃过来的幸存者。开场时你躺在塔顶，`save.player.hp` 不重置——**你身上已经不剩什么了**。

你不记得自己的名字。你只记得两件事：**往上跑**，和**别回头**。

你不知道的是：你之所以不记得，是因为**上一次你也来过这里**。你走到了最后，你选择了走，然后你把自己关于这座塔的记忆剪掉了，好让自己能继续往上。剪掉记忆的手艺，是塔心教的。

**② 引路人（唯一的说话人）**

一个蹲在塔顶边缘、披着石灰色斗篷的人。他教你建塔，语气平淡，从不解释自己是谁。

**他不是 NPC，他是上一个通关的人。** 他当年也站在你现在的位置，也把伊格纳斯打倒过，也看见了那颗心——然后他**没有走**。他留下了，成了塔心的守夜人之一。

他教你，是因为他需要一个人来接班。他冷淡，是因为他已经送走过很多人。

> 多周目（第二局及以后）他会说出真相：**「你不记得我。我记得你。我就是你上一次没走成的那一半。」**

**③ 伊格纳斯（Boss，熔渊之主）**

9 米高的石制巨像，阶段 I 是岩甲，阶段 II 是熔火。

**他不是魔王。** 他是这座城最后一个还在守的人——一个把自己的身体炼成壳、把熔心包在胸口、不让地火把它烧穿的人。

- **阶段 I「岩甲形态」**：他把心裹在岩甲里。你打他，他不还嘴，只是挡。**法术（蓝）能穿透岩甲打到心**——因为记忆能穿过壳。
- **阶段 II「熔火形态」**：岩甲被你打碎了。他露出本体：不是更凶，是**更老、更累、更亮**。他身上的裂纹是他自己烧出来的。这时候他的弱点变成**物理（白金）**——因为壳没了，你终于能"直接碰到他"。

他的台词从来不威胁你，他只是**疲惫**。这是本作反派的全部魅力：**他不恨你，他只是不能让那颗心停。**

### 3.3 塔心（熔心核）

平台中央那口竖井下面，跳着的东西。你的任务是守它 4:30。

它不是道具，它是**人**。是这座城第一个决定留下的人。它一直在跳，因为只要它跳，城就还有温度，人就还能多活一天。

**结局的核心问题**：4:30 到了，心快停了。你是**走**（上去，继续逃），还是**接**（留下，成为下一颗心）？

本作只做一个结局——**接**。因为这是一款关于"舍弃"的游戏，而不是关于"逃出去"的游戏。

## 四、五幕结构（精确到秒）

单局时间轴来自 `src/core/config/flow.json`：

```
0:00–0:20  wake        醒来
0:20–0:40  prep        准备期
0:40–2:10  boss1       阶段 I 岩甲
2:10–2:25  transition  转阶段
2:25–4:05  boss2       阶段 II 熔火
4:05–4:30  rage        狂暴
4:30       ended       结算
```

| 幕 | 主题 | 时段 | 玩家在想什么 | 剧情给什么 |
|---|---|---|---|---|
| **一** | **迷惘** | 0:00–0:40 | "我在哪？我为什么要跑？" | 只给碎片，不给答案。第一次里世界一闪而过，看见"往下走的人"。 |
| **二** | **成长** | 0:40–2:10 | "我会建塔了。我能打它。" | 引路人开始教你；伊格纳斯第一次开口；你发现岩甲下面有心跳。 |
| **三** | **舍弃** | 2:10–2:25 | "我为什么不能直接上去？" | **全片最重的 15 秒**。整段坠入里世界。真相的一半：你抛下过人。 |
| **四** | **决绝** | 2:25–4:05 | "他不是敌人。但我必须打。" | 伊格纳斯露出本体；引路人说出"他不是拦你"；你选择不回头。 |
| **五** | **新生** | 4:05–4:30 | "现在每个决定都算数。" | 熔岩到脚踝。你接过那颗心。第一声心跳是你自己的。 |

### 第一幕 · 迷惘（0:00–0:40）

**基调**：不解释。观众和玩家一样什么都不知道。

- `t=3s`（表）：旁白「你还记得自己在跑。／你不记得跑向哪里。」
- `t=10s`（**里，2.2s**）：第一次里世界。旁白「往下走的人，背影一模一样。／你数到第七个就醒了。」——**这是全片第一次进入里世界，也是玩家第一次看见"里世界"这个机制**。冷青一闪，结晶化 +1。
- `t=17s`（表）：引路人「塔心还亮着。说明有人替你守过。／别浪费。」
- `t=25s`（表）：引路人「石头记得形状。／把塔建在它想站的地方。」
- 首次建塔（事件）：引路人「塔不是墙。／塔是你肯留下的一部分。」

**设计意图**：第一幕只做三件事——教机制、立基调、埋一个"往下走的人"的钩子。**不出现"魔王"这个词。**

### 第二幕 · 成长（0:40–2:10）

**基调**：玩家开始享受战斗。剧情开始不安。

- `boss1 起`（表）：伊格纳斯「又一个。／上一个也说自己只是路过。」
- `Boss 血量 < 75%`（**里**）：旁白「岩甲下面有心跳。／你听见过它，只是没承认。」
- 首次 `WeaknessExposed{core}`（**里**）：引路人「蓝的。／他护着的不是自己，是那个。」——**第一次把"心"和"弱点"绑在一起**。
- `Boss 血量 < 50%`（表）：伊格纳斯「你越打，它越凉。／你知道吗？」
- 首次 `ExecutionEnded`（表）：旁白「击碎的声音，／像有人在很远的地方关上一扇门。」

**设计意图**：玩家在这一幕**变强**（学会布塔、学会击破），但每一句台词都在告诉他"你打的是错的东西"。**成长本身是一种误入。**

### 第三幕 · 舍弃（2:10–2:25）

**基调**：全片重心。这 15 秒是"可操作的过场"，玩家还能动，但剧情在说话。

- `transition 起`（**里，长**）：旁白「记忆是这座城的第二层。／你现在站在它里面。」——整段转阶段都在里世界，熔岩上涨、桥断裂在冷青滤镜下发生。
- `t=134s`（里）：引路人「想上去，先松开手里的东西。／你一直不肯松。」
- `t=139s`（里）：旁白「你想起上一关。／你没有回头。／那不是勇敢，是舍不得回头。」
  ——**这是全片第一次把"你"钉在道德上。** 玩家此时正在经历"舍弃"：岩甲碎了、外环开了、你要重新布塔——**机制上的"重布"就是叙事上的"放下"。**
- `boss2 起`（表，冷青褪去）：伊格纳斯「壳没了。／现在你看见我了——／我不好看，但我一直在。」

**设计意图**：这一幕把**机制与叙事完全重合**。转阶段让你"重布所有塔"，剧情说的是"松开手里的东西"。玩家不需要读文档就能感受到——**他正在失去他建起来的一切**。

### 第四幕 · 决绝（2:25–4:05）

**基调**：不再有误解。玩家知道了，还是选择打。

- `t=150s`（表）：引路人「他不是拦你。／他是唯一还在守的人。」
- `首次 KneeBroken`（表）：旁白「跪下的时候，／石头也会疼。」
- `首次 TauntStarted`（表）：引路人「让他转过去。／有些话只能从背后说。」
- `Boss 血量 < 30%`（**里**）：伊格纳斯「你要的是上去。／我要的是它别停。／我们其实不冲突。」
  ——**Boss 自己说出了核心矛盾。** 这句话是整部剧情的题眼。
- `rage 起 4:05`（表）：旁白「熔岩到脚踝了。／现在每个决定都算数。」

**设计意图**：决绝不是"更狠"，是**明知对方是对的，仍然要动手**。因为"留下来"不是伊格纳斯能替玩家做的决定。

### 第五幕 · 新生（4:30）

- `win`（**里**）：引路人「心还在跳。／只是换了一个人的胸腔。」
- `win + 4s`（表，结晶化满）：旁白「你听见的第一声，／是自己的。」
- `lose: core_destroyed`（表）：旁白「塔心灭了。／城又沉了一寸。」
- `lose: player_out_of_lives`（表）：旁白「你倒在石头上。／石头记得你的重量。」
- `lose: timeout`（表）：旁白「熔岩盖过眼睛的时候，／你没有闭眼。」

**设计意图**：胜利不是"打倒 Boss"，是**"接住那颗心"**。失败也不是惩罚，是"这座城又沉了一寸"——**你尽力了，只是不够**。

## 五、表里世界的触发规则（机制规格）

| Boss 行为 | 里世界时长 | 叙事理由 |
|---|---|---|
| 首次进入 `boss1` | 0（表） | 先让玩家看清敌人 |
| 血量首次 < 75% / 50% / 30% | 2.4–3.2 s | "你打得越深，记忆越近" |
| `WeaknessExposed{core}` 首次 | 2.6 s | 弱点是心，所以看见心 |
| `ExecutionEnded` 首次 | 1.8 s | 击破的余韵 |
| `KneeBroken` 首次 | 1.8 s | 石头也会疼 |
| `FreezeFull` 首次 | 1.6 s | 冻结=时间停=里世界最容易开 |
| **`transition` 全程** | **15 s（整段）** | 全片唯一的长镜头 |
| `PlayerDied` | 2.2 s | 走马灯只给一句 |
| `MatchEnded{win}` | 4.0 s | 新生 |

**结晶化（crystal）**：每次进入里世界 `innerVisits++`，屏幕边缘结晶强度 = `min(innerVisits × 0.16, 0.72)`。到第五幕时屏幕四周已经是玻璃——**玩家自己也正在变成塔的一部分**。这是本作唯一"不可逆"的视觉进度条。

## 六、多周目（深度来源）

`StoryDirector` 接收 `runIndex`（0 = 首局）。第二局起，部分 cue 用 `altOnReplay` 换成**真相版台词**：

| 触发点 | 首局 | 第二局起 |
|---|---|---|
| `t=17s` 引路人自我介绍 | 「塔心还亮着。说明有人替你守过。」 | 「塔心还亮着。／我替你守的。／第二次了。」 |
| `transition` 引路人 | 「想上去，先松开手里的东西。」 | 「你又来了。／上一次你松开了，然后你忘了。」 |
| `win` 引路人 | 「心还在跳。只是换了一个人的胸腔。」 | 「这次别忘。／记住我，就是记住你自己。」 |

**为什么这能加深游戏**：单局 4:30 讲不完一个完整故事，但**重复挑战**本身就是叙事——玩家的"再来一局"在故事里意味着"这个人又回来了，又忘了一次"。存档不跨局，记忆不跨局，**只有引路人记得**。

这直接呼应平台的接龙规则：上一棒留下 `exit_hook`，下一棒读到它——**我们的关卡自己就是一次接龙，而玩家是那个反复重开的人**。

## 七、与现有系统的接缝（工程事实）

| 项 | 事实 |
|---|---|
| 契约 | **不改 `events.ts`**，不动 `CONTRACT.lock`。剧情层只 `bus.on`，不 `emit`。 |
| 逻辑层 | `src/story/StoryDirector.ts` 是纯 TS，不 import three，可在 Node 下跑 vitest。 |
| 表现层 | `src/ui/StoryPresenter.ts` 纯 DOM + CSS，只改 canvas 的 `filter`，`dispose()` 还原。 |
| 接线 | `src/main.ts`：`createGame` 之后建 director，`app.onTick` 里 update，`app.onSync` 里 present。 |
| Boss 事件依赖 | 当前 `BossEntity` 未接线，`BossHpChanged / WeaknessExposed` 暂不触发。因此**主线剧情全部由 `MatchPhaseChanged` + 绝对时刻驱动，现在就能跑**；Boss 相关 cue 是"接上 Boss 后自动生效"的增强层。 |
| 平台红线 | 无 alert/confirm、无 IP 词汇、无外部资源、纯程序化视觉。 |

## 九、写作规范（改台词时必须遵守）

1. **单行 ≤ 22 汉字**，用 `\n` 主动断行。断行位置要落在语义停顿上，不要断在词中间。
2. 标准 cue 总长 ≤ 2 行；关键 cue（`durationMs ≥ 4000`）≤ 3 行。
3. **不解释设定**。不出现"这个世界""规则是""传说中"。所有信息靠画面和语气给。
4. **不用感叹号**。全片只有一个感叹语气的地方也不给。
5. 引路人：短句、陈述、不解释自己。伊格纳斯：疲惫、不威胁、偶尔反问。旁白：第二人称"你"，冷，像回忆而不是解说。
6. 每句台词必须能回答"这句话为什么非得在**这一刻**说"——答不上就删。
