<a id="一"></a>
## 一、一句话与核心命题

> **你不是第一个来这座塔的人。塔心不是机器，是上一个不肯走的人留下的心跳；而你要打的那个"魔王"，是唯一还在替它守夜的人。**

**核心命题**：这款游戏问的不是"你能不能打赢"，而是——

> **当你知道挡路的人是对的，你还要不要走过去？**

伊格纳斯的答案是不走。引路人的答案是走了、然后回来。你的答案，游戏留给你在 4:30 里自己给。

<a id="二"></a>
## 二、为什么用表里世界（机制即叙事）

本作单局只有 **4:30**，没有一秒可以停下来播过场。

所以剧情不能"停下来讲"，只能**在战斗的缝隙里渗出来**。于是有了双世界：

| | 表世界（surface） | 里世界（inner） |
|---|---|---|
| 画面 | 橙红熔岩、黑曜石孤塔、火星上浮 | 冷青、降饱和、边缘结晶化 |
| 玩家在做什么 | 建塔、闪避、击破 | **什么都做不了，只能听**（1.8–4.6 秒，不打断操作） |
| 叙事功能 | 讲"发生了什么" | 讲"为什么会这样" |
| 触发时机 | 阶段推进、布塔、血量变化 | **Boss 转阶段、弱点暴露、击破、膝盖碎裂、冻结满、玩家受伤/死亡** |

**核心设计：里世界只在"战斗最激烈的那一瞬"打开。**

- Boss 岩甲张开、露出蓝色核心的那 3 秒 → 玩家眼前一冷，听见一句不属于这个世界的记忆；
- Boss 从岩甲蜕成熔火的 15 秒转阶段 → 玩家整段坠入里世界，看见这座城是怎么沉的；
- 熔岩涨到胸口 → 里世界最后一次打开，你终于听见它在数你的心跳。

这不是"战斗时弹对话框"，而是**战斗本身就是叙事的节拍器**。你打得越狠，看到的越多；你越强，越接近那个不想知道的真相。

**技术上**：里世界用 **canvas 的 CSS filter + 叠加层**实现，不碰渲染管线、零 GPU 开销、WebGPU 与 WebGL2 回退两条路都生效。每次进入里世界，屏幕边缘的"结晶"累加一层——**这是玩家的进度条，也是他的异化程度**。

<a id="三"></a>
## 三、世界设定

### 熔岩地心城（第 21 号世界）

一座正在沉下去的城市。岩浆每分钟上涨一米，出口在最顶端。

**但这不是自然灾害。** 这座城建在一颗**还在跳的心**上面——「熔心」。城靠这颗心的热量活着，也因为它而必须一直往下沉：心每跳一次，地火就涨一寸。城里的人一代代往上搬，搬到无处可搬，最后只剩塔顶。

你脚下这座孤塔，是最后一块还没被淹的地方。

<a id="四"></a>
## 四、三个存在

### ① 你（玩家）

从上一关逃过来的幸存者。开场时你躺在塔顶，`save.player.hp` **不重置**——你身上已经不剩什么了。

你不记得自己的名字。你只记得两件事：**往上跑**，和**别回头**。

你不知道的是：**你上一次也来过这里。** 你走到了最后，你选择了走，然后你把自己关于这座塔的记忆剪掉了，好让自己能继续往上。剪掉记忆的手艺，是塔心教的。

> 这就是为什么游戏里你"什么都想不起来"——不是失忆，是**你自己选的**。

### ② 引路人（唯一的引导者）

一个蹲在塔顶边缘、披着石灰色斗篷的人。他教你建塔，语气平淡，从不解释自己是谁。

**他不是 NPC，他是上一个通关的人。** 他当年也站在你现在的位置，也把伊格纳斯打倒过，也看见了那颗心——然后他**没有走**。他留下了，成了塔心的守夜人之一。

他教你，是因为他需要一个人来接班。他冷淡，是因为他已经送走过很多人。

> **第二周目他会说出真相**：「你不记得我。我记得你。我就是你上一次没走成的那一半。」

### ③ 伊格纳斯（Boss，熔渊之主）

9 米高的石制巨像，阶段 I 是岩甲，阶段 II 是熔火。

**他不是魔王。** 他是这座城最后一个还在守的人——一个把自己的身体炼成壳、把熔心包在胸口、不让地火把它烧穿的人。

- **阶段 I「岩甲形态」**：他把心裹在岩甲里。你打他，他不还嘴，只是挡。**法术（蓝）能穿透岩甲打到心**——因为记忆能穿过壳。
- **阶段 II「熔火形态」**：岩甲被你打碎了。他露出本体：不是更凶，是**更老、更累、更亮**。他身上的裂纹是他自己烧出来的。这时弱点变成**物理（白金）**——壳没了，你终于能"直接碰到他"。

他的台词从来不威胁你，他只是**疲惫**。这是本作反派的全部魅力：**他不恨你，他只是不能让那颗心停。**

### ④ 塔心（熔心核）

平台中央那口竖井下面，跳着的东西。你的任务是守它 4:30。

它不是道具，它是**人**。是这座城第一个决定留下的人。它一直在跳，因为只要它跳，城就还有温度，人就还能多活一天。

**结局的核心问题**：4:30 到了，心快停了。你是**走**（上去，继续逃），还是**接**（留下，成为下一颗心）？

本作只做一个结局——**接**。因为这是一款关于"舍弃"的游戏，而不是关于"逃出去"的游戏。

### 第三幕 · 舍弃（2:20–2:35）

**基调**：全片重心。这 15 秒是"可操作的过场"——玩家还能动，但剧情在说话。

| # | 触发 | 世界 | 说话人 | 台词 | 时长 |
|---|---|---|---|---|---|
| a3_transition | transition 起 | **里** | 旁白 | 记忆是这座城的第二层。／你现在站在它里面。 | 4.0s |
| a3_letgo | 接上句 | **里** | 引路人 | 想上去，先松开手里的东西。／你一直不肯松。 | 4.4s |
| a3_prevlevel | 接上句 | **里** | 旁白 | 你想起上一关。／你没有回头。／那不是勇敢，是舍不得回头。 | 4.6s |
| a3_boss2 | boss2 起 | 表 | 伊格纳斯 | 壳没了。／现在你看见我了——／我不好看，但我一直在。 | 4.4s |

**设计意图**：这一幕把**机制与叙事完全重合**。

转阶段让玩家"重布所有塔"（岩甲碎了、外环开了、属性互换），剧情说的是"松开手里的东西"。玩家不需要读文档就能感受到——**他正在失去他建起来的一切**。

`a3_prevlevel` 是全片第一次把"你"钉在道德上：上一关你逃了，那不是勇敢，是舍不得回头。而这一关，你没有回头路了。

**三句连播**（afterCue 串接）覆盖整个 15 秒转阶段，是全片唯一的长镜头。

<a id="六"></a>
## 六、剧情如何咬住游戏进程（触发器设计）

这是 v2.0 相对 v1.0 的核心改进。

### 问题：绝对秒数是脆弱的

v1.0 的剧情大量用 `tSec`（第 3 秒、第 17 秒…）。这在三种情况下会崩：

1. **玩家提前打完 Boss** → 阶段跳了，但台词还在按秒数排队，出现"已经在打阶段 II，旁白还在讲准备期"的错位；
2. **阶段时长调整** → 所有秒数要重算，改一个 `flow.json` 就得重排全部台词；
3. **玩家反复死亡/复活** → 时间轴继续走，剧情却和玩家实际经历脱节。

### 解法：用进程信号驱动

v2.0 引入了四个**进程驱动触发器**（`src/story/types.ts`）：

| 触发器 | 语义 | 为什么它比秒数好 |
|---|---|---|
| `phaseProgress {phase, pct}` | 进入某阶段后走过 pct% | 阶段时长改了台词自动跟着走；阶段被跳过时台词自然作废，不会错位 |
| `bossHpBelow {pct}` | Boss 血量首次跌破 | 锚在"打到什么程度"，而不是"打了多久" |
| `playerHpBelow {pct}` | 玩家血量首次跌破 | 承接平台"血量接力"规则，是叙事而非战斗数值 |
| `coreHpBelow {pct}` | 塔心血量首次跌破 | 塔心快灭时说的话 |
| `lavaAbove {y}` | 熔岩首次升到某高度 | **本作最贴叙事的进程信号**：脚踝、膝盖、胸口 |
| `lavaRising {risePerSec}` | 熔岩开始快速上涨 | 狂暴开始的听觉标记 |

### 现在的分布

```
34 条常规 cue 的触发源（实测，node 统计）：
  event          12 条  ← Boss/玩家/塔的真实行为
  phaseProgress   7 条  ← 主力（相对进程，不是墙上钟）
  afterCue        6 条  ← 连播串接
  phase           4 条  ← 阶段入口
  bossHpBelow     3 条
  coreHpBelow     1 条
  playerHpBelow   1 条
```

**0 条 cue 依赖绝对秒数**（v1.0 有 11 条）。`tSec` 触发器保留在契约里以兼容，但当前配置已完全不用。

`lavaAbove` / `lavaRising` 两个触发器已实现并有测试覆盖，但当前配置里熔岩三句改用 `afterCue` 串接（因为狂暴期只有 30 秒，连续上涨中三条各自抢时刻会互相吞掉，串接更稳）。

### 关键工程细节：两条防错设计

**① 快照补读（修掉一个会让第一幕整段消失的 bug）**

时间轴（`MatchTimeline`）在 `createGame` 内部就已 `init` 并发出首个 `MatchPhaseChanged{wake, 0}`。剧情层通常在之后才 `init`，因此**会错过那个事件**——`currentPhase` 永远是 null，`phaseProgress` 没有起点，第一幕全部台词静默消失。

修复：`init` 时从只读快照补读当前阶段。

```ts
const snap = b.snapshot();
if (snap && snap.phase) {
  currentPhase = snap.phase;
  phaseEnteredAt = snap.tSec;
  phaseSpanSec = phaseDurations.get(snap.phase) ?? 0;
}
```

**② flow.json 兜底**

即使调用方忘记传 `phaseDurations`，引擎也会从 `flow.json` 读取阶段时长，保证 `phaseProgress` 不会整段失效。这条有专门的防回归测试。

## 七、表里世界切换规则

| Boss / 玩家行为 | 里世界时长 | 叙事理由 |
|---|---|---|
| 首次进入 `wake`（10 秒处） | 2.6 s | 让玩家第一次认识"里世界"这个机制 |
| Boss 血量 <75% / <50% / <30% | 2.8–4.2 s | 打得越深，记忆越近 |
| `WeaknessExposed{core}` 首次 | 3.0 s | 弱点是心，所以看见心 |
| `ExecutionEnded` 首次 | 2.2 s | 击破的余韵 |
| `KneeBroken` 首次 | 2.2 s | 石头也会疼 |
| `FreezeFull` 首次 | 2.4 s | 冻结＝时间停＝里世界最容易开 |
| **`transition` 全程** | **13.7 s（三句连播）** | 全片唯一的长镜头 |
| 玩家 HP <35% | 3.0 s | 你的伤是逃过来的证明 |
| 玩家死亡 | 2.6 s | 走马灯只给一句 |
| 熔岩到胸口 | 4.2 s | 最后一次打开 |
| `MatchEnded{win}` | 4.0 s | 新生 |

**结晶化（crystal）**：每次进入里世界 `innerVisits++`，屏幕边缘结晶强度 = `min(innerVisits × 0.16, 0.72)`。

到第五幕时屏幕四周已经是玻璃——**玩家自己也正在变成塔的一部分**。这是本作唯一"不可逆"的视觉进度条。

**总量控制**：里世界累计约 46.2 秒，占单局 17.1%（13 条）。这个比例经过设计——超过 25% 会变成 MV（玩家失去操作感），低于 8% 则机制没有存在感。

<a id="八"></a>
## 八、多周目：深度从哪来

`StoryDirector` 接收 `runIndex`（0 = 首局）。第二局起，三条关键 cue 换成**真相版**：

| 触发点 | 首局 | 第二局起 |
|---|---|---|
| `wake 85%` 引路人 | 「塔心还亮着。说明有人替你守过。／别浪费。」 | 「塔心还亮着。／我替你守的。第二次了。」 |
| `transition` 引路人 | 「想上去，先松开手里的东西。／你一直不肯松。」 | 「你又来了。／上一次你松开了，然后你忘了。」 |
| `win` 引路人 | 「心还在跳。／只是换了一个人的胸腔。」 | 「这次别忘。／记住我，就是记住你自己。」 |

**为什么这能加深游戏**：

单局 4:30 讲不完一个完整故事。但**重复挑战本身就是叙事**——玩家的"再来一局"在故事里意味着"这个人又回来了，又忘了一次"。

存档不跨局，记忆不跨局，**只有引路人记得**。

这直接呼应平台的接龙规则：上一棒留下 `exit_hook`，下一棒读到它——**我们的关卡自己就是一次接龙，而玩家是那个反复重开的人**。

<a id="九"></a>
## 九、写作规范（改台词必须遵守）

1. **单行 ≤ 22 汉字**，用 `\n` 主动断行。断行位置落在语义停顿上，不要断在词中间。
2. 标准 cue 总长 ≤ 2 行；关键 cue（`durationMs ≥ 4000`）≤ 3 行。
3. **不解释设定**。不出现"这个世界""规则是""传说中""顾名思义"。
4. **不用感叹号**。全片一个都不给。
5. **引路人**：短句、陈述、不解释自己。**伊格纳斯**：疲惫、不威胁、偶尔反问。**旁白**：第二人称"你"，冷，像回忆而不是解说。
6. 每句台词必须能回答"这句话为什么非得在**这一刻**说"——答不上就删。

以上规则由 `tools/story/lint-story.mjs` **机器校验**，改完跑一遍，0 项违规才算通过。
