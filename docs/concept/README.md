# 美术参考图组 · 熔心孤塔

> 给渲染 Agent 的视觉锚点。**所有图都不是最终画面，是"照着调到这个感觉"的目标。**
> 生成模型：gpt-image-2.6-sunburst-2k ｜ 2026-11-08

## 贯穿全组的三条铁律

1. **光只从下面来。** 熔岩是唯一光源。向下的面亮、向上的面全黑，没有一处被上方照亮。任何一张图里出现"顶光是亮的"，就是做错了。
2. **暗部要真的暗。** 近黑（#0a0806 一带），不是深灰。亮部（熔岩裂缝、符文）要极亮，中间调几乎没有。
3. **低多边形岩块感。** 大块面、硬边、flatShading。不要细腻的石头纹理，要"整块烧过的玄武岩"。

## 001-spire-top.png · 氛围定调

第一人称站在台边，看出去是熔岩海与穹顶。人物剪影做尺度参照。

**用来看**：整体色温、对比度、雾的浓度、火星的密度。
**不用来**：布局（这张的布局不准，以 002 为准）。

## 002-spire-layout.png · 布局总览

唯一一张能看清整体结构的图：中央八棱塔 + 塔顶冷青光柱 + 中环 + 四条石桥 + 外环四个塔柱 + 熔岩海。

**用来看**：各元素的相对位置与尺寸比例。这张的布局和 `docs/tickets/M1-01-render.md` 的场景表完全一致。
**关键细节**：塔本身必须有明显的高度——它是一根柱子，不是一块台子。

## 003-tower-top.png · 塔顶平台

圆形石台，边缘一圈符文槽发出稳定橙光，外圈是 1.1 m 破损矮墙，中央后方是地脉灯塔的冷青光柱根部。

**用来看**：
- 符文槽的发光方式：是"槽里流淌的液体"，不是"贴上去的贴图"
- 石板缝的走向：不规则多边形，缝里略透光
- 矮墙的破损感：块与块之间错位，不是整齐一圈
- 冷青光的穿透力：在橙色环境里，这一道青是最强的视觉锚点

## 004-ring-platform.png · 中环平台与塔位

环形平台绕塔基一圈，四个六边形塔位底座均布，边缘无栏杆，直接悬在熔岩上。

**用来看**：
- 塔位底座的具体形态：矮六边形石台，侧面一圈符文环，台面是平的（上面什么都没有，等玩家建塔）
- 平台外缘的处理：直接断掉，没有栏杆，制造"会掉下去"的恐惧
- 石桥的形态：窄、平、无栏，只有两侧微微高起的边
- 塔基与地面的接缝：塔是"长在地上"的，不是放上去的

## 005-tower-shaft.png · 塔身

八棱柱，竖向黑曜石棱线反光，螺旋外廊绕塔而上，塔基没入熔岩。

**用来看**：
- 棱线：八个角上是抛光的黑曜石条，反射下方熔岩，是全图唯一的镜面高光
- 外廊：宽而薄，底部是悬挑的，带一道矮边
- 岩板：大块堆叠，接缝错开，缝里透橙光
- 从下往上的亮度梯度：越靠近熔岩越亮

## 006-lava-closeup.png · 熔岩海

贴地的近景，黑色结壳裂成不规则多边形，裂缝里是白热橙红，几处正在冒泡溅射。

**用来看**：熔岩着色器的目标效果。
**实现提示**：不要用贴图。用 fbm 噪声做 `ridge = 1.0 - smoothstep(0, 0.04, abs(fbm - 0.5))`，脊线处发光，这就是裂缝。结壳部分压到 `#2a0705` 一带，裂缝处给 `#ffd27a` 到 `#ff5a12` 的渐变。

## 交付给渲染 Agent 时怎么说

> 这六张图是目标，不是素材。你要做的是用代码程序化生成等价的观感：
> 石头用 `IcosahedronGeometry` / `BoxGeometry` + flatShading + 程序化噪声贴图；
> 熔岩用 TSL 自定义节点材质 + fbm 裂缝；
> 符文用 `RingGeometry` + `MeshBasicMaterial` 配合 Bloom；
> 冷青光柱用透明圆柱 + 边缘菲涅尔 + Bloom。
> **不要去找 GLB 模型**，现在这套东西全部要用代码长出来。
