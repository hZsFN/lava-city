# Demo 流畅度与手感打磨

基线：`e82c071`，包含已合并的 PR #13、新 Boss 模型和落岩恢复修复。
分支：`perf/demo-polish-20261108`。本轮不改动原工作区的未提交文件。

## 行为改善

1. 镜头、武器与塔动画每个渲染帧同步一次。原来只在 60 Hz 固定逻辑步同步，高刷屏无逻辑步的帧不响应最新转向；慢帧补步又重复执行整套表现同步。现在固定步只同步攻击所需镜头，渲染帧统一更新外观，并最后恢复苏醒、教程阅读、转阶段和传送镜头。
2. 攻击射线使用本步移动后的眼位，镜头矩阵立即更新。镜头更新只更新自身与父级，不递归刷新武器子树。
3. 输入缓冲复用一个对象；点击/切形态边沿只消费一次，按住状态保留到所有补步。原先 100 ms 帧补 6 步时，后 5 步会得到未按住输入；现在蓄力与持续攻击覆盖全部 100 ms。
4. 失焦、隐藏页面、退出 Pointer Lock、进入俯视时清除移动、鼠标按住和未消费边沿。主循环的待处理边沿同步清空，防止回来补打一枪。
5. 长时间停手后，小幅转向立即响应；仍丢弃长间隔的大位移尖峰，保留锁定初期保护和角度限制。
6. 演出镜头的临时 Vector3 改为实例内复用，减少逐逻辑步/渲染帧的分配。
7. 塔材质贴图使用 Vite 部署基路径，修复子目录或平台 ZIP 部署时向网站根路径取图的问题。

## 已知限制

完整 gate 仍被基线契约锁阻断，实际命令为 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/gate.ps1 -SkipPack`：

```text
src/core/events.ts 被修改（期望 5d3798ffca05…，实际 9d97345de61d…）。契约只有 S0 能改；需要新事件请在 handoff 里提「契约申请」。
[gate] FAIL contract (exit 1, 2.0s)
```

本轮未修改该契约或锁，也未将 gate 标记为通过。类型、全量单测和打包独立执行。

本地 Vite 服务成功启动，但内置浏览器访问返回 `net::ERR_CONNECTION_TIMED_OUT`；本机浏览器自动化随后因无法可靠识别当前 URL 而停止。未完成浏览器实机试玩或真实 GPU 帧率对照，不声明 FPS 提升百分比。

位置仍跟随权威 60 Hz 逻辑坐标，本轮改善转向与表现更新，未加入位置插值，以免引入镜头穿碰撞边界风险。

## 建议人工复核

- 使用 120/144 Hz 屏幕，停手后小幅转向、连续转向、跳跃移动并攻击。
- 制造低帧率，确认持续开火/重击蓄力速度不随逻辑补步变慢，单次点击不重复触发。
- 按住鼠标切出窗口、Esc 解锁、B 进入俯视，再返回，确认无卡键或自动攻击。
- 检查开场、教程书、Boss 转阶段、胜利传送和 K 锁血功能；检查子目录部署的五种塔贴图。
