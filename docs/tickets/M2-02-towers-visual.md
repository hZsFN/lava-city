# 票 M2-02 · 塔的表现层（视觉与开火）

> 依赖：M1-03 已完成（石头看得见）。
> 目标：让"塔防"这半边真正立起来——玩家建的东西必须看得见、有分量、开火有反馈。
> 只允许改 `src/render/`（新增 `Towers.ts`）与 `src/core/config/visual.json`。**逻辑层一行不动**，塔的所有状态都从 `snapshot().towers` 与事件读。

## 【现状问题】

现在建完塔只是一个方块，开火没有表现。玩家花 3 个熔核建的东西，看不出它在干活——这等于塔防系统在视觉上是空的。

## 【要做的五块】

### 1. 塔位圆盘的四种状态

现在只有颜色变化，太弱。改成**形变 + 光**双重表达：

| 状态 | 视觉 |
|---|---|
| `locked` | 暗灰石台，符文环熄灭，表面有细微裂纹（不可建） |
| `open` | 符文环**缓慢呼吸**（周期 2.4 s，亮度 0.35↔0.65），台面上方飘一个淡淡的金色光柱（高 0.6 m，透明度 0.12） |
| `occupied` | 光柱消失，台面被塔占用，符文环变成该塔的属性色并常亮 |
| `submerged` | 整个圆盘下沉，只露边缘一圈，符文全灭，周围有熔岩气泡 |

数据来源：`TowerSlotStateChanged{slotId, state}` + `visual.json` 的槽位坐标。

### 2. 五种塔的造型（全部程序化，低多边形）

统一风格：**石制底座 + 发光核心 + 属性色**。五米以内能一眼分清是哪一种。

| 塔 | 造型 | 高度 | 主色 |
|---|---|---|---|
| **弩炮塔** | 石台 + 两根交叉的粗木梁 + 中间一根水平弩臂，弩臂端头是金属爪 | 2.8 m | 物理白金 `#f0e6cf` |
| **符文聚能塔** | 石台 + 一根细高的六棱晶柱，柱中嵌三颗悬浮的发光符文（缓慢自转） | 3.4 m | 法术蓝 `#4aa8ff` |
| **寒晶塔** | 石台 + 一簇不规则的冰蓝色棱锥（4–6 根，高低错落），顶部一根最高的 | 3.0 m | 冰青 `#7fd8ff` |
| **震地锚塔** | 石台 + 一根粗短的圆柱 + 顶部一块悬空的重型石锤（缓慢上下浮） | 2.4 m | 物理白金 + 橙芯 |
| **嘲讽图腾** | 石台 + 一根歪斜的木桩 + 顶上挂三个兽骨铃铛（轻微摆动） | 2.6 m | 暖橙 `#ff7a1e` |

**所有塔都朝向外侧（背对塔心）**，炮口/晶柱朝向要朝着最近的 Boss 方向缓慢转向。

### 3. 开火表现（这是"塔在干活"的唯一证据）

- **弩炮塔**：射出一根高速细长光矢（0.25 m 长，白金），带 0.15 s 拖尾，命中处一个 0.15 s 的火花闪光。
- **符文聚能塔**：从晶柱顶端射出一束持续 0.12 s 的蓝色光束（细圆柱 + 加法混合），命中处一圈符文扩散环。
- **寒晶塔**：无射弹，向周围 18 m 内持续扩散一圈极淡的霜雾环（每 2 s 一次，透明度 0.08 逐渐扩散到 0）。
- **震地锚塔**：不发射，每 3 s 石锤砸下，地面出现一圈同心冲击波（半径 0→8 m，0.4 s）。
- **嘲讽图腾**：无开火，但被 Boss 攻击时整根木桩剧烈抖动 0.3 s，铃铛乱响。

全部走对象池（每类最多 24 个实例），不许每次新建几何体。

### 4. 塔的耐久表现

`TowerHpChanged{hp, maxHp}`：
- `hp/maxHp < 0.6`：塔身上出现 2–3 道发光裂缝
- `< 0.3`：裂缝变红，塔体轻微倾斜（3°），并有持续的黑烟粒子
- 归零：整塔向内塌陷（0.4 s 缩放到 0.2 并下沉），同时一圈碎石向外抛

### 5. 建塔 / 升级 / 拆除的动效

- **建塔**：石台先升起一圈光，然后塔体从地面"长出来"（0.5 s，Y 方向从 0 缩放到 1），最后核心闪一次。
- **升级**：塔体整体放亮一下 + 一圈光从上往下扫过，塔顶多一个属性色的光环。
- **拆除**：反向播放"长出来"的动画。

## 【性能】

- 11 个塔位，每个塔最多 ~30 个 mesh，全部按材质合并 → **塔相关 draw call 必须 ≤ 12**。
- 开火特效全部走对象池，禁止运行时 `new Geometry`。
- 交付时贴 `renderer.info.render.calls` 在"满塔 + 全部开火"状态下的数字。

1. `npm run typecheck` + `npm run build` + `node kit/tools/check.mjs out/` 全过。

## 【不许做的事】

- 不许改 `src/towers/`（逻辑层）、不许新增事件。
- 不许用外部模型（虽然现在白名单允许 gltf，但塔必须是程序化几何，跟场景风格一致）。
- 不许让塔的自发光亮到抢走 Boss 弱点的视觉优先级——**弱点暴露时全场最亮的东西必须是弱点**

## 【收尾记录 · 2026-11-08】建塔 UI：鼠标、塔型面板、换塔

改动：`src/main.ts`（面板 + 点击逻辑）、`src/game/GameLoop.ts`（`replaceTower`）、`src/game/Input.ts`（`setLockAllowed`）。

- **鼠标**：进俯视时退出 Pointer Lock，并关掉 Input 的"点画布就重新锁定"。原来点塔位那一下会把指针锁回屏幕中心 —— 光标刚出现就消失，`clientX/Y` 也冻在中间，塔位全点歪。俯视时画布换成十字光标。实测：进俯视后 `requestPointerLock` 调用数不再增长，回第一人称点一下照旧锁定。
- **塔型面板**：右侧常驻，五行 `属性 · 伤害/间隔 · 射程 · 造价`，当前手上的那一种高亮，底部一行写特效（碎甲 / 灼烙 / 冻结 / 打断 / 嘲讽）。数值全部现读 `config/towers.json`，改平衡不用回来动 UI。
- **换塔**：已占用的塔位再点一下，以**最新点下去的塔型**为准。`Game.replaceTower(slotId, kind)` 先按 `build.sellRefundRatio`（0.7，向下取整）卖掉旧塔，再建新塔；折返后仍买不起就不动旧塔；同种塔直接拒（提示"已经是X了"），避免白吃一次折价。实测：弩炮（造价 3）→ 符文（造价 3），折返 2，熔核净耗 1。
- **位置**：面板放右下角（Boss 血条在顶部居中、熔核药丸在右下角下方），1280×720 与 1920×1080 实测与可见 HUD 元素零重叠。
- 验收：`npm run gate` 全绿（contract / typecheck / vitest 293 / build / pack 8 项）；无头探针实测建塔 → 换塔 → 同种塔拒绝三步，页面零报错。。
