# 票 M1-02 · 渲染返工：把"霓虹"改回"石头"

> 触发：M1-01 技术指标全过（47 draw call / 117k 三角 / 84 fps / check 10 项），但**三张截图里只有 shot2 能用**。
> 范围：只改 `src/render/**` 与 `src/core/config/visual.json`。**不重写架构**，只调材质、自发光、Bloom、噪声贴图。

## 【诊断：现在错在哪】

**shot2（俯视熔岩海）是好的** —— 结壳裂纹、白热缝隙、黑红对比都对，说明熔岩 shader 本身没问题。

**shot1（塔顶平视）和 shot3（底层仰望）是崩的**，三个原因：

1. **所有发光元素一起 Bloom，画面变成霓虹灯。** 符文槽、岩脉、护罩环、熔心核全开自发光 + Bloom 0.85，加起来是一片橙色糊墙。真实的熔岩地心应该是**九成的黑、一成的亮**，现在是反过来。
2. **那些"血管纹"是噪声贴图用错了地方。** 现在 512² 程序化噪声同时做 `map`、`bumpMap` 和**自发光**，于是岩壁上到处是发光的细线，像电路板或者血管。岩石只有凹凸，不该自己发光。
3. **熔心核是一个发光的土豆。** 现在是一颗自发光球加两根面条环，跟"被护罩包住的能量核心"没有关系。

## 【修法（按优先级，每条都要做）】

### 1. 砍掉岩体的自发光，只留凹凸（最关键）

`Spire.ts` 的岩体材质：
- **删掉** emissive / emissiveMap 相关的一切设置
- `map` 保留程序化噪声，但**对比度压到 0.6**（现在太花）
- `bumpMap` 保留，`bumpScale` 从现值降到 **0.18**
- 噪声的**波长放大 4 倍**：现在是一片细密的纹路，应该变成**大块的斑驳**（3–5 米尺度一块）。做法是把 canvas 噪声的 `scale` 参数降 4 倍，或者对纹理做 4×4 的下采样再放大。

判据：**关掉所有灯以后，岩体应该什么都不亮。**

### 2. 符文槽：从"灯管"变成"槽里的一线光"

现在符文是宽度可见的亮条，`MeshBasicMaterial` 全亮，Bloom 一炸就是一整条灯带。
- 宽度减半
- 颜色从纯橙改成 `#c4400e`（更深的橙，不是亮橙）
- 改成 `MeshStandardNodeMaterial` + `emissiveIntensity 1.6`（**不是 Basic**，Basic 不吃 Bloom 阈值，等于恒定满亮）
- 只在槽的**底部**窄条发光，槽壁不发光

### 3. Bloom 收紧

`PostFX.ts`：
- 阈值 `0.72 → 0.86`（只有真正白热的地方才炸）
- 强度 `0.85 → 0.42`
- 半径稍减

判据：**整幅画面里能炸开的地方不超过三处**。

### 4. 熔心核重做

现在是一颗发光球。改成三层：
- **外层护罩**：半透明球壳（`transparent, opacity 0.12`，菲涅尔边缘亮），半径 2.4
- **中层核心**：半径 1.1 的球，`emissiveIntensity 2.2`，**颜色 #ff8a3a 不是 #ffd27a**（现在太白太热）
- **内层黑核**：半径 0.55，接近纯黑，让核心看起来是"壳"不是"实心"
- 两根面条环删掉，改成**一圈 8 根竖直的悬浮石柱**，柱间是暗的
- 核心底下加一盏向上打的光，照亮塔心竖井内壁

### 5. 环境光整体压暗，把黑找回来

- `HemisphereLight` 强度降到现在的 **0.55 倍**
- `FogExp2` 密度 `0.0032 → 0.0055`（远景更快融进黑）
- 后处理合成 pass 里，**暗部往 #05070a 压**（现在暗部是褐红，画面没有黑）
- 曝光 `1.05 → 0.92`

判据：**画面里应该有大片接近纯黑的区域**，现在没有。

## 【验收】

重新出三张 1080p 截图，覆盖原三个机位，然后逐条对照：

1. `npm run typecheck && npm run build && npm run pack && node kit/tools/check.mjs out/` 全过。
2. 三张图里**每一张都能看到明显的黑**（至少 30% 面积是暗部）。
3. shot1 里符文是**细的一线光**，不是灯管。
4. shot3 里熔心核能分辨出"外壳 / 核心 / 环柱"三层。
5. **把 Bloom 关掉截图**，画面依然能看懂结构（说明结构不是靠发光撑起来的）。
6. Draw call 与帧时间不得恶化（≤ 55 / ≤ 14 ms）。

## 【不许做】

- 不许重写渲染架构、不许换后处理方案
- 不许动 `events.ts`、`src/boss/**`、`src/player/**`
- 不许为了提高亮度去调曝光——**这票的目标是把画面变暗**
