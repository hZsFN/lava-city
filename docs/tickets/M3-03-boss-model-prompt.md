# 给 Opus 的 Boss 建模提示词（离线版·自包含）

> 用途：Opus 不在本机、看不到项目代码。让它输出**一份自包含的 TS 文件**，由我们合并。
> 造型完全不限制，只给接口和技术边界。

---

你在给一个网页游戏设计并实现一个 Boss 的三维模型。**你看不到项目代码，所以你只需要输出一份自包含的 TypeScript 文件**，我们会把它合并进去。

技术栈：TypeScript + Three.js。模型全部靠代码生成，没有建模软件、没有 GLB、没有贴图文件。

## 一、这个游戏是什么

《熔心孤塔》——第一人称「塔防 × Boss 战」的单局制动作游戏，单局 4 分 30 秒。

玩家站在一座石制高塔的塔顶平台上，四周是被熔岩海包围的深渊，头顶是几十米高的地心穹顶。玩家在塔顶布下防御塔牵制 Boss，自己拿武器补刀，击破它暴露的弱点。

**关键设定：这个场景没有天空光。熔岩是唯一光源，所有光从下方打上来。**

## 二、你要做的东西

Boss 名「伊格纳斯」，地心城深处的东西。高度 8–11 米。玩家 1.7 米第一人称视角，在 20 米外**仰视**它。

两个阶段：
- **阶段 I「岩甲形态」**：弱点在正面胸口，属性法术（冷蓝）
- **阶段 II「熔火形态」**：弱点在背部，属性物理（白金）；双膝可被打碎，碎后跪地

八个技能决定身体必须能做什么：

| 技能 | 身体动作 |
|---|---|
| 岩拳横扫 | 一条手臂做 120° 横扫 |
| 跃击 | 整只跳起来砸向玩家 |
| 地脉汲取 | 持续引导，胸口吸能 |
| 岩柱升腾 | 站立，玩家脚下冒岩柱 |
| 熔岩吐息 | 从嘴/发射口喷 20 米锥形火 |
| 熔岩冲撞 | 沿直线冲锋 |
| 火雨 | 站立，全场落 10 个火球 |
| 自燃爆发 | 周身 10 米爆炸 |

所以它必须有：**两条能挥的臂、能跳、能冲、有发射口、胸口有东西、背部有东西、膝盖能被打碎跪下。**

## 三、你要输出的文件

文件名 `IgnisRig.ts`，一个自包含模块。结构如下，**接口一字不能改**：

```ts
import * as THREE from 'three/webgpu';

export interface IgnisRig {
  root: THREE.Group;      // 世界原点，y=0 是脚底
  rig: THREE.Group;       // 整体缩放/抬升用
  hips: THREE.Group;      // 髋部，所有腿挂这里
  torso: THREE.Group;     // 躯干，所有上肢挂这里
  chest: THREE.Group;     // 胸腔，弱点 core 的锚点
  head: THREE.Group;      // 头
  shoulderL: THREE.Group; // 左肩，绕它转就是挥臂
  elbowL: THREE.Group;    // 左肘
  shoulderR: THREE.Group;
  elbowR: THREE.Group;
  legL: THREE.Group;      // 左腿根
  kneeL: THREE.Group;     // 左膝，绕它转就是屈膝
  footL: THREE.Group;
  legR: THREE.Group;
  kneeR: THREE.Group;
  footR: THREE.Group;
}

export interface IgnisBuild {
  rig: IgnisRig;
  /** 所有"岩石主体"网格：阶段 II 换材质时会整体替换材质 */
  stoneMeshes: THREE.Mesh[];
  /** 所有"自发光"网格：裂缝、核心、关节，保持发光 */
  glowMeshes: THREE.Mesh[];
  /** 阶段 II 才显示、阶段 I 隐藏的网格（比如背部裂缝、膝部核心） */
  phase2Meshes: THREE.Mesh[];
}

export function createIgnisRig(): IgnisBuild;
```

**坐标约定**（很重要，接进来直接就用）：
- 世界原点在脚底，`y = 0` 是地面
- 面朝 **+Z** 方向
- 总高 9 米左右（阶段 I），我们会在外面用 `rig.scale` 拉到 11 米做阶段 II
- `x` 正方向是它的右手边

**四个弱点必须落在这些位置附近**（我们也用同样的坐标判断命中）：

```
core  : (0,  5.6,  1.9)   半径 1.1   正面胸口
back  : (0,  7.0, -1.9)   半径 1.3   背面
kneeL : (-0.95, 2.2, 0.2) 半径 0.6   左膝
kneeR : ( 0.95, 2.2, 0.2) 半径 0.6   右膝
```

意思就是：**胸口、背、左右膝这四个位置必须看得见、能对准攻击。玩家要从 20 米外一眼认出"那里是弱点"** —— 建议用"岩壳裂开、里面透出光"的方式表达。

## 四、硬边界

1. **只有几何体。** 不允许任何外部文件。全部用 `BoxGeometry` / `IcosahedronGeometry` / `CylinderGeometry` / `DodecahedronGeometry` / `LatheGeometry` / `ExtrudeGeometry` / 自定义 `BufferGeometry` 拼。允许 `flatShading: true`。
2. **性能**：三角面 4 万以内，独立 mesh 不超过 80 个。
3. **光从下往上**。别做自上而下的明暗；材质要在**没有环境光**时依然有层次——真实场景里它下半身被熔岩照着，上半身几乎全黑。
4. **两个阶段的差异要一眼可见**。阶段 II 不是换色，是让玩家 0.5 秒内认出"它变了"。你可以让 `phase2Meshes` 在阶段 II 出现、`stoneMeshes` 换材质来实现。
5. **TypeScript strict 通过**，不要用 `any`。

## 五、造型：完全自由

**不要参考任何现成游戏的 Boss。** 不要恶魔法师、不要岩石魔像、不要龙、不要骷髅骑士——那些都有人做过。

自己想：**一个生活在地心、由岩石和熔岩构成的、8 到 11 米高的、会打人的东西，长什么样才没见过？**

可以想的方向（不必局限）：
- 它是不是根本不是"一个生物"？
- 身体结构可以不符合任何地球生物吗？
- 它有没有可能是"一处会动的景观"而不是"一个角色"？
- 两个阶段能不能是**两种完全不同的存在形态**，而不只是同一副骨架换皮？

唯一的功能约束就是上面那句话：两条能挥的臂、能跳、能冲、有发射口、胸口有弱点、背部有弱点、双膝可碎。
