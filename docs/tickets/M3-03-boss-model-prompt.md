# 给 Opus 的 Boss 建模提示词

> 用途：让 Opus 独立设计并实现《熔心孤塔》的 Boss 模型。
> 造型**完全不限制**，只给技术边界和功能需求。

---

你在给一个网页游戏做一个 Boss 的**程序化三维模型**。技术栈是 TypeScript + Three.js（WebGPU 渲染器），模型全部靠代码生成，没有任何建模软件、没有 GLB 文件。

## 一、这个游戏是什么

《熔心孤塔》——第一人称「塔防 × Boss 战」的单局制动作游戏，单局上限 4 分 30 秒。

玩家站在一座石制高塔的塔顶平台上，四周是被熔岩海包围的深渊，头顶是几十米高的地心穹顶。塔心（熔心核）是整座城的能量核心，玩家在塔顶布下防御塔牵制 Boss，同时自己拿武器补刀，击破它暴露出来的弱点。

**光的关键设定：这个场景里没有天空光。熔岩是唯一光源，所有光从下方打上来。**

## 二、你要做的东西

Boss 名叫「伊格纳斯」，它是地心城深处的东西，是玩家这一关要打倒的对象。

高度 8–11 米。玩家是 1.7 米的第一人称视角，站在 20 米开外的平台上**仰视**它。

它有两个阶段：

- **阶段 I「岩甲形态」**：弱点在**正面胸口**，属性是法术（冷蓝色）。
- **阶段 II「熔火形态」**：弱点在**背部**，属性是物理（白金色）；另外**双膝**可以被打碎，碎掉后它会跪地。

这里有八个技能，它们决定了这个身体必须能做什么动作：

| 技能 | 身体要做的动作 |
|---|---|
| 岩拳横扫 | 用一条手臂做 120° 横扫 |
| 跃击 | 整只跳起来砸向玩家 |
| 地脉汲取 | 持续引导，胸口吸取能量 |
| 岩柱升腾 | 站在原地，玩家脚下冒岩柱 |
| 熔岩吐息 | 从嘴里（或某个发射口）喷出 20 米长的锥形火 |
| 熔岩冲撞 | 沿直线冲锋 |
| 火雨 | 站在原地，全场落下 10 个火球 |
| 自燃爆发 | 周身 10 米爆炸 |

所以它必须：**有两条能挥的手臂、能跳、能冲、有嘴或发射口、胸口有东西、背部有东西、膝盖能被打碎跪下。**

## 三、必须遵守的硬边界

**1. 只有几何体。** 不允许任何外部模型文件、贴图文件。所有形状用 `BoxGeometry`/`IcosahedronGeometry`/`CylinderGeometry`/`DodecahedronGeometry`/`LatheGeometry`/自定义 `BufferGeometry` 在代码里拼出来。贴图只能用 `CanvasTexture` 现场画。

**2. 不能改骨架命名。** 现有关节层级是：

```
root
└── rig
    ├── hips
    │   ├── torso
    │   │   ├── chest      ← 弱点 core 挂这里
    │   │   ├── head
    │   │   ├── shoulderL → elbowL      （R 侧同理）
    │   │   └── shoulderR → elbowR
    │   ├── legL → kneeL → footL        （R 侧同理）
    │   └── legR → kneeR → footR
```

**3. 四个弱点挂点必须存在且可见**，位置由 `src/boss/parts.ts` 的 `localOffset` 决定，你可以微调数值但不能改语义：

```ts
core:  { r: 1.1, attr: 'arcane',   localOffset: [0, 1.2, 1.8] }   // 胸口前方
back:  { r: 1.3, attr: 'physical', localOffset: [0, 1.6, -1.9] }  // 背面
kneeL: { r: 0.6, attr: 'physical', localOffset: [-0.95, 4.6, 0.2] } // 左膝
kneeR: { r: 0.6, attr: 'physical', localOffset: [ 0.95, 4.6, 0.2] } // 右膝
```

意思就是：**胸口、背、左右膝这四个位置必须是看得见、能对准攻击的部位。** 玩家要从 20 米外一眼认出"那里是弱点"。

**4. 性能。** 整只 Boss 的三角面控制在 4 万以内，独立 mesh 不超过 80 个（太碎会掉帧）。用 `flatShading: true` 是允许且鼓励的。

**5. 光从下往上。** 别在模型上做自上而下的明暗关系。所有高光、边缘光都应该是自下而上的。材质要能在**没有环境光**的情况下依然有层次——因为真实场景里它下半身被熔岩照着，上半身几乎全黑。

**6. 两个阶段的差异要明显。** 阶段 II 不是换个颜色，要能让玩家在 0.5 秒内认出"它变了"。

## 四、造型：完全自由

**不要参考任何现成游戏的 Boss。** 不要恶魔法师、不要岩石魔像、不要龙、不要骷髅骑士。那些都有人做过。

你要自己想一件事：**一个生活在地心、由岩石和熔岩构成的、8 到 11 米高的、会打人的东西，长什么样才没见过？**

可以想的方向（但不必局限于此）：
- 它是不是根本不是"一个生物"？
- 它的身体结构可以不符合任何地球生物吗？
- 它有没有可能是一处"会动的景观"而不是一个"角色"？
- 它的两个阶段，有没有可能是**两种完全不同的存在形态**，而不只是同一副骨架换个皮？

唯一的功能约束就是第三节最后那句话：两条能挥的臂、能跳、能冲、有发射口、胸口有弱点、背部有弱点、双膝可碎。

## 五、交付

改一个文件：`src/boss/BossEntity.ts`，重写 `buildBody()` / `buildArm()` / `buildLeg()` 三个方法，以及构造函数里的材质定义。

必须通过：`npm run typecheck`（TypeScript strict）和 `npm run build`。

交付时说明：
1. 你的设计概念，一句话
2. 三个阶段各自长什么样
3. 四个弱点在造型上怎么被"看出来"
4. 用了多少个 mesh、大概多少面

现成的骨架代码在 `src/boss/BossEntity.ts`（约 1000 行），动画、技能、行为树、破绽控制器都已经写好了，你只动造型那三个方法。
