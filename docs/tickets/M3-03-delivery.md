# IgnisRig.ts 交付说明（票 M3-03）

## 1. 设计概念（一句话）

伊格纳斯不是生物，是地心城遗留的一座**自走式冶炼炉**：八角窑身当躯干、坩埚当头、砧锤与钳夹当手、活塞炉脚当腿。

## 2. 两个阶段

**阶段 I「岩甲形态」**：整体是暗黑玄武岩砌成的封闭窑炉。只有下半身被熔岩映成暖色，六道余烬裂缝沿窑身下部的棱线发亮，炉底一圈火线。胸口炉门四框三栅，栅后透出一颗**冷蓝色地脉结晶**——全身唯一的冷色，20 m 外一眼可见。背部是一个封死的圆形冷却阀门（环 + 塞），没有任何发光。

**阶段 II「熔火形态」**（外部把 `phase2Meshes` 设为可见、替换 `stoneMeshes` 材质、`rig.scale` 拉到 11 m）：
- 背部阀门崩开，白金色排气口核心从塞子里鼓出，四道放射状白金裂缝。
- 双膝活塞缸前方鼓出白金色膝部核心。
- 坩埚口冒出三支火冠，总高拔高近 2 m，剪影明显改变。
- 肩周悬浮六块余烬矿渣。
蓝色消失、白金出现、剪影长高、肩周多出碎块——四个变化叠加，0.5 s 内可辨。

## 3. 四个弱点怎么被"看出来"

| 弱点 | 世界坐标（阶段 I） | 造型表达 |
|---|---|---|
| core | (0, 5.6, 1.5) r0.95，前缘 z≈2.45 | 炉门栅栏后的冷蓝结晶，全身唯一冷色 |
| back | (0, 7.0, −2.1) r0.95，后缘 z≈−3.05 | 阶段 II 白金排气口 + 四道裂缝，嵌在阀门环内 |
| kneeL / kneeR | (±0.95, 2.2, 0.7) r0.44 | 阶段 II 从膝部活塞缸前方鼓出的白金核心 |

均落在需求给定的判定球内（已用脚本验证：四个判定球内都有发光网格顶点）。

## 4. 规模

- 68 个独立 mesh（39 岩石 / 29 发光，其中 16 个为阶段 II 专属）
- 2356 三角面（上限 4 万，余量极大；flatShading 的低面数就是这套造型的风格）
- 阶段 I 包围盒：x ±4.0，y 0～9.32，z ±2.6

## 5. 接入说明

- `import { createIgnisRig } from './IgnisRig'`，`scene.add(build.rig.root)`。
- `phase2Meshes` 默认 `visible = false`。
- 岩石材质开启了 `vertexColors`，顶点色按世界高度烘焙（脚部偏暖、上身偏冷灰），用于无环境光时的层次。若阶段 II 替换材质，建议新材质也开 `vertexColors: true` 以保留该层次；不开也不会报错。
- 发光网格共四种材质：余烬橙（裂缝/关节/炉底/火冠/矿渣）、冷蓝（core）、白金（back、双膝）、以及炉底火线单独的双面余烬材质。
- 挥臂绕 `shoulderL/R` 旋转，屈肘绕 `elbowL/R`，跪地绕 `kneeL/R` 旋转 x 轴；`head` 自带 0.28 rad 前倾，吐息时再绕 x 增大即"倾倒坩埚"。
- 所有关节 Group 的世界坐标见下，可直接用于 hitbox 对齐：

```
hips (0,3.6,0)  torso (0,4.5,0)  chest (0,5.6,0)  head (0,7.7,0.2)
shoulderL (-2.6,7.1,0)  elbowL (-3.05,5.0,0.3)   shoulderR/elbowR 对称
legL (-0.95,3.6,0)  kneeL (-0.95,2.2,0.2)  footL (-0.95,0,0)   右侧对称
```

- Node 下以 `three` 核心别名运行构建函数，统计 mesh/三角/包围盒/弱点覆盖，结果如第 3、4 节。
