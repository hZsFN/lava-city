# 票 M3-02 · Boss 造型返工（替换 M3-01 的几何方案）

> 触发：主人反馈现在的 Boss「不好看」。
> 范围：只改 `src/boss/BossEntity.ts`（几何 + 材质 + 关节命名不变）和 `src/boss/config.ts` 里的尺寸常量。**技能、行为树、破绽控制器、事件契约一律不动。**

## 【核心设计：它不是一个站着的人，它是从熔岩里爬出来的东西】

现在这版难看，根因是**做成了"人形巨人"** —— 圆柱胳膊 + 球形胸 + 八角头，比例像玩偶，材质是一身灰，跟"熔渊之主"这个名字没关系。

新版只坚持一个概念：**它一直在往上爬，从没爬完。**

- **阶段 I**：腰部以下全在熔岩里，观众只看到躯干、双臂、头从熔岩里支起来。它撑着地，像要把自己拔出来。
- **转阶段**：它**真的站起来** —— 整体上移 2 m，双腿从熔岩里拔出，身高从可见 9 m 变成 11 m。熔岩同时上涨，追着它往上淹。

这个改动有个额外好处：**两个阶段的身高差 9 m / 11 m 是设计文档原本就写好的**，现在有了解释，不是随手填的数。

## 【骨架（阶段 II 全高，单位米）】

```
y=11.0  ┌ 头顶
        │ 头 1.4 m 高（y 9.6–11.0）
y= 9.6  ├ 颈（y 9.2–9.6，短、粗）
        │ 躯干 4.2 m（y 5.4–9.6）
        │   ├ 胸甲 y 7.0–9.6，宽 3.6，厚 2.4
        │   └ 腰甲 y 5.4–7.0，宽 3.0，厚 2.0
y= 5.4  ├ 髋（左右 x ±1.05）
        │ 大腿 y 5.4→2.8（长 2.6，半径 1.0→0.9）
        │ 小腿 y 2.8→0.35（长 2.45，半径 0.85→0.75）
        │ 脚 y 0–0.35，长 1.8，宽 1.3
y= 0    └ 地面 / 熔岩面

肩：x ±2.6，y 8.4–9.8（肩甲向上翘，最高点 y 9.8）
上臂：肩→肘，肘在 y 6.4，长 2.4，半径 0.72
前臂：肘→腕，腕在 y 3.6，长 2.8，半径 0.92（**前臂比上臂粗**，这是力量感的来源）
拳：y 3.0–3.9，半径 1.15，不规则多面体
```

**阶段 I = 同一副骨架整体下沉 2 m。** 熔岩面 y=0 遮住 y<0 的部分，所以只露出 y 0→9。不要做两套模型。

## 【七个必须做对的细节】

1. **头是裂开的，不是一张脸。** 用一个 `IcosahedronGeometry(0.72, 0)` 拉成 `scale(1.1, 1.35, 1.0)`，然后从头顶往下劈一条 **竖直的发光裂缝**（一块 `BoxGeometry(0.09, 1.3, 0.12)` 自发光，贴在正面）。**没有眼睛、没有嘴。** 裂缝就是它的眼。
2. **胸口是一个炉膛，不是一颗球。** 现在的球形核心太像"机器人的能量球"。改成：胸甲正面挖一个凹陷（用一圈 8 块小岩片围成一个洞），洞底是熔岩色自发光平面，中间浮一颗小一点的核心球（半径 0.55，`#4aa8ff` 冷蓝，**冷色才衬得出**）。岩甲壳就是这 8 块小岩片，暴露时向外翻开。
3. **肩甲必须向上翘。** 现在肩是平的，所以剪影是"梯形"，很钝。把肩甲做成向外上方倾斜 25° 的大块，剪影立刻从"方"变"锐"——这是本票最重要的一条。
4. **前臂比上臂粗。** 人类是反过来的，所以现在看起来像娃娃。巨兽的前臂应该是锤子。
5. **拳头不是球，是碎的。** `IcosahedronGeometry(1.15, 0)` + 每个顶点随机偏移 ±0.15 m，表面裂 3–4 道发光缝。
6. **背部的裂缝要能被看见。** 从肩胛（y 9.3）到腰（y 5.6）开一条纵向裂隙，宽 0.22，深 0.3，里面是流动熔岩材质。阶段 II 才亮。玩家在它背后时这应该是**整幅画面里最亮的一条线**。
7. **膝盖是两块翘出来的岩片，不是球。** 阶段 II 暴露时岩片向两侧翻开，里面是白热的关节。

## 【材质（这是"难看"的另一半原因）】

现在整只 Boss 是一个 `MeshStandardMaterial(color:#2e2a28)`，太平了。改成**三种材质分层**：

| 用在哪 | 材质 | 参数 |
|---|---|---|
| 主体岩块 | `MeshStandardNodeMaterial` + flatShading | `color: #14100e`，`roughness 0.94`，`metalness 0.05`，**比现在暗一个档** |
| 棱线 / 边缘 | 抛光黑曜石 | `color: #0a0806`，`roughness 0.08`，`metalness 0.95` —— 这层会反射下方熔岩，是唯一的高光 |
| 裂缝 / 核心 / 关节 | 自发光熔岩 | `#ff5a12` 到 `#ffd27a` 渐变，用同一套 fbm 裂缝节点（和 M1 的熔岩海共用），强度 2.2，交给 Bloom |

**关键：主体的暗度必须压到接近黑（#14100e）。** 现在 #2e2a28 是"灰石头"，在橙色雾里看着脏；压到近黑以后，所有亮度都来自裂缝，对比度立刻出来。

## 【光照】

- **Boss 身上不要放任何从上往下打的灯。**
- 胸口炉膛内放一盏 `PointLight(#ff6a1e, 260, 22)`，会从内部照亮胸甲内壁和下颌。
- 双拳各一盏 `PointLight(#ff4400, 90, 12)`，因为拳头有裂缝。
- 弱点暴露时，对应部位加一盏短促的 `PointLight`，颜色按属性（蓝=法术、白金=物理）。

## 【验收】

1. `npm run typecheck` 零错误。
2. 起 `http://localhost:5173/src/boss/preview.html`，**站在它脚下仰视**截一张图：要求能看到"肩宽腰窄头小"的锐利剪影，能看见胸口炉膛里的蓝光。
3. 切阶段 II：截图里它必须比阶段 I 高出一截（整体上移 2 m），且腿部可见、膝部两块岩片翻开着。
4. 走到它背后截图：背部裂缝必须是画面最亮的一条线。
5. 全身材质在无光环境下（关掉环境光）应几乎全黑，只有裂缝发光。

## 【不许做的事】

- 不许引入任何外部模型或贴图文件（白名单里现在虽然有 glb 了，但我们的美术方向是纯程序化，换成 GLB 会跟 M1 的渲染风格打架）。
- 不许改关节命名（`hips/torso/chest/head/shoulderL/R/...`），行为树和技能都按这些名字挂的。
- 不许改 `parts.ts` 里四个 hitbox 的 `localOffset` 名与语义，只允许微调数值。
