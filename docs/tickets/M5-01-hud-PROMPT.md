# M5-01 提示词（直接复制给 TRAE）

> 任务：实现票 M5-01（HUD 与结算页）。

先 `git pull`，然后按顺序读三个文件：
1. `docs/tickets/M5-01-hud.md` —— 完整需求，六块界面加结算页
2. `src/core/events.ts` —— 全部事件名与 `Snapshot` 结构，HUD 只从这里拿数据
3. `src/core/config/ui.json` 与 `visual.json` —— 颜色、字号、属性色都从这两个文件读

## 硬性要求

1. **只新建 `src/ui/` 下的文件**（建议 `src/ui/hud.ts` + `src/ui/hud.css`），允许改 `index.html` 的样式块。
   **不许碰 `src/render/`、`src/game/`、`src/boss/`、`src/towers/`。**

2. 原生 DOM + CSS。**不引任何 UI 框架，不装依赖。**

3. 只订阅事件总线 + 读 `bus.snapshot()`。**不许 import three，不许持有任何 3D 对象。**

4. 所有颜色 / 字号 / 动效时长从 `ui.json` 读，**不许写死在 CSS 里**。属性色必须引用 `visual.json`：法术 `#4aa8ff`、物理 `#f0e6cf`。

5. **DOM 更新统一在 `app.onSync` 里 flush**（进队列，每帧最多刷一次）。不许在事件回调里直接改 DOM。

6. 六块界面必须全做：
   - 左下角：HP 条（宽 260 高 10）、形态图标（44px）+ 名字、过热条（仅法术形态）
   - 顶部中央：倒计时 `M:SS` + 当前阶段中文名
   - 顶部：Boss 双段血条（宽 620 高 14，上段当前阶段、下段灰掉），左右各一个抗性图标，下方挂 debuff 层数
   - 中央：准星（十字）+ 破绽环（64px，按 `WeaknessProgress` 填充，满时变白金并浮现 `[F] 击破`）
   - 屏幕边缘：弱点方向箭头，指向弱点方位，颜色 = 弱点属性色
   - 右下角：熔核数 + 战术点数

7. 结算页（`MatchEnded` 时全屏淡入 0.4 s）：大字「守护成功 / 塔心熄灭」、副标题「用时 M:SS · 击破 N 次」、评级 S/A/B/C、伤害构成条形图（塔 / 普攻 / 击破）、底部「再来一局」。

8. **开局可能只有 1 点血，这是规则允许的正常状态，不许显示成异常或警告。**

9. **不许显示死亡次数。** 血量归零即失败，我们不管理复活。

10. **不许出现「你在打黑客松」「AI 生成」这类出戏文案。** 验收会扫。

## 验收

- `npm run typecheck && npm run build && node kit/tools/check.mjs out/` 全绿
- 起 `npm run dev`，用调试手段制造五种状态，各截一张图放 `docs/shots/hud/`：
  ① 开局 1 点血 ② 阶段 I 弱点暴露、破绽环半满 ③ 阶段切换瞬间 ④ 结算页成功 ⑤ 结算页失败
- 1080p 下 HUD 总覆盖面积不超过屏幕 18%，不遮挡准星周围 120×120 的中心区
- 所有文字字号 ≥ 12px、对比度 ≥ 4.5:1
