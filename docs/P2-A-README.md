## 二、我做了哪些东西（按"解决什么问题"讲）

### 1. 能走能跳能闪，不会穿墙
自己写了一套最简碰撞（AABB）。平台、台阶、墙都能正确站/撞；走下 20 cm 台阶会自动吸附，不会抖；掉进熔岩直接判死。

### 2. 血量按"接力棒"规则走，不写死 100
按主办方《02-血量接力规则》改的：

- 开局血量从存档 `WL.save()` 读，不再固定 100
- 删掉了"脱战自动回血""复活""三条命"
- 被 Boss 打一下固定 -1，受击后 1.2 s 无敌（防止一个技能连扣）
- 血归零只做一件事：调 `WL.failLevel()`，不回血不复活

### 3. 两把武器，伤害只算"基础值"
按你定的**方案一**：

- 武器只负责"打出去多少基础伤害 + 是物理还是法术"
- 抗性、弱点 ×2.5 / ×1.2 全部交给 Boss 自己算
- 这样以后 Boss 改数值，武器这边不用跟着改，不会出现两边算两遍的问题

### 4. 击破（核心爽点）
弱点暴露 → 你打它累积"破绽值" → 满 100 进入 3 秒可击破 → 按 F 播放 1.2 秒处决 → 结算 = Boss 当前阶段最大血量的 12% 真实伤害。

### 5. 战术视图
Tab 打开后时间降到 0.15×，可以用"每击破一次 +1"的战术点远程搬塔；Boss 转阶段额外送 1 次免费重布。

### 6. 第一人称武器外观（新）
从 Poly Haven 下了两个 **CC0 免费商用** 模型（长剑、手枪），放进 `public/models/`，游戏里跟着相机显示，切形态换武器，攻击有挥砍/后坐动画和蓝色枪口闪光。

### 7. 投射物
火花、岩锚用的飞行物系统：有对象池（最多 64 发）、按速度飞行、每帧做线段检测防穿模、命中或超时自动回收。

## 三、一局里数据是怎么流的

```
鼠标/键盘
   ↓
输入层 Input（左右键、Q、F、视角 yaw/pitch）
   ↓
CombatController（按当前形态把输入分给剑或枪）
   ↓
武器模块（算出基础伤害 + 物理/法术属性）
   ↓
相机射线打到 Boss 身上 → 把命中点换算到 Boss 本地坐标
   ↓
IgnisBoss.takeDamage(基础伤害, 属性, 命中点)
   ↓
Boss 自己算抗性/弱点 → 扣血 → 发 DamageDealt 事件
   ↓
HUD / 音效 / 武器动画 / 破绽值累积
```

关键原则：**武器和 Boss 之间只通过事件和这一个函数通信**，谁也不直接改对方的内部状态。

## 四、数值从哪来

- 玩家手感、武器伤害、投射物速度：`src/core/config/player.json`
- Boss 血量、抗性、技能伤害、弱点属性：**唯一权威是 `src/boss/IgnisBoss.ts` 顶部的 `SKILLS` / `WEAKNESS_*` 常量表**
- 代码里不复制 Boss 的数值，避免两边不一致

## 六、还没做完的（不藏着）

1. **击破的 12% 真伤还没扣到 Boss**：`IgnisBoss` 只有普通 `takeDamage`（会吃抗性），需要一个"无视抗性的扣血"接口，属于 Boss 那边（S3）。
2. **Tab 战术视图还没接按键**：模块和单测都好了，但 `main.ts` 里还没监听 Tab。
3. **岩锚命中弱点后的"把自己拉过去"没做**：数据已经算出来了，但玩家还没有瞬移/位移接口。
4. **武器外观的位置/角度要实机看一眼**：模型是真实比例，我按包围盒估了摆位，可能需要在浏览器里微调。
