# HTML5 / 原生 JavaScript

本目录包含两份可独立复制的网页示例。每份目录都有自己的 index.html、global-items.json 和 shared/save-protocol.js；复制时保留完整目录。

- `examples/01-minimal-html5-level/`：接档、失败/救援与通关。
- `examples/02-effect-relic/`：hp、max_hp、cleanse 的入场道具效果。

通用规则与工具见解压根目录。运行根目录 mock-runner.html 选择示例和它自己的道具声明；也可用本地 HTTP 服务打开整个交付包。投稿只打包你的游戏运行目录，不要把整个工具包压进去。

外链作品另读 `../../接入方式/外链/外链接力接入指南.md`；其中的 SDK 示例位于 `../../接入方式/外链/example/`。
